Flag icons drawn as plain SVG geometry for the language switch (no emoji, which render as letters on Windows).
`en.svg`: Union Jack (United Kingdom) for English. `tr.svg`: flag of Türkiye (official proportions: crescent
circles at G/2 and G/2 + G/16 from the hoist, radii G/4 and G/5; star circumscribed radius G/8).
